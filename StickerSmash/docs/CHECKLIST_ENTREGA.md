# Lista de comprobación de entrega académica

Marca cada punto únicamente después de comprobarlo.

## Capítulos 1–3: entorno, navegación y diseño

- [ ] Instalación completada con `npm install` sin `--force` ni `--legacy-peer-deps`.
- [ ] `npm run typecheck` termina sin errores.
- [ ] `npx expo-doctor` no informa problemas pendientes.
- [ ] `npx expo config --type public` termina correctamente.
- [ ] Se ven las pestañas Inicio y About.
- [ ] About muestra los cinco datos académicos correctos.
- [ ] Diseño se adapta a pantalla móvil y navegador.

## Capítulos 4–6: imagen, modal y gestos

- [ ] Se elige una foto desde galería en Android.
- [ ] Se elige una foto desde galería en iOS.
- [ ] Se elige una imagen desde el ordenador en Web.
- [ ] El bottom sheet se abre y se cierra.
- [ ] Se pueden añadir varios stickers.
- [ ] Cada sticker se puede arrastrar con el dedo o ratón.
- [ ] Los stickers permanecen dentro de los límites del lienzo.

## Capítulos 7–8: captura, permisos y personalización

- [ ] El botón Guardar muestra un indicador durante el proceso.
- [ ] No acepta pulsaciones repetidas durante la captura.
- [ ] Android: se solicita permiso y aparece el PNG en Galería.
- [ ] iOS: se solicita permiso y aparece el PNG en Fotos.
- [ ] Web: se descarga un PNG válido.
- [ ] Se abre el archivo guardado y se comprueba que incluye fondo y todos los stickers.
- [ ] Se verifica el icono en la instalación nativa.
- [ ] Se verifica el splash screen en la instalación nativa.
- [ ] La barra de estado es legible.

## Entregables

- [ ] ZIP sin `node_modules`.
- [ ] README y guía de instalación.
- [ ] `package.json` y `package-lock.json` completos tras `npm install`.
- [ ] Capturas/GIF reales en `evidencias/`.
- [ ] Repositorio GitHub real y commits por capítulos.
- [ ] Se ha revisado el estado de `docs/VALIDACION.md` y no se marcan pruebas pendientes como aprobadas.
